# 知时智农 · 怎么打开

一共有四种打开方式，按你的场景挑一种就行。

---

## 一、在线版 · 最推荐（手机、电脑都能开，任何网络都行）

浏览器打开：

    https://leeforword.github.io/zhishi-zhinong/

手机打开后可以「安装」到桌面，变成一个独立图标，全屏运行，
下次不用再翻书签 —— 具体步骤见第六节。

> 网址里的 leeforword 换成部署仓库的 GitHub 用户名。
> 如果还没部署，看 docs/部署与安装.md。

---

## 二、电脑上用 · 单文件版（发给别人最省事）

双击 **`知时智农-单文件版.html`** 即可。

就这一个文件，不用管别的。拷 U 盘、发微信、扔桌面都能用。
（约 400 KB，所有代码和地图数据都打包在里面了）

---

## 三、电脑上用 · 完整版

1. 进入 `web` 文件夹
2. **双击 `index.html`**

功能完全一样，只是文件分成多个，方便以后改代码。

> 推荐使用 **Chrome 或 Edge**（Windows 自带 Edge 即可）。

---

## 四、同一 WiFi 下的手机 · 扫码（不用部署也能试）

手机浏览器不能直接打开电脑上的本地文件，
所以要由电脑把网页「分享」到同一个 WiFi 下。

1. 手机和电脑连 **同一个 WiFi**
2. 双击 **`start.bat`**
3. 会弹出两个窗口：
   - 黑窗口：显示手机访问地址和二维码
   - 浏览器：自动打开应用，以及一个**大二维码页面**
4. 用手机相机 / 微信扫浏览器里的二维码
5. 手机浏览器里就能用了

**连不上怎么办？**

| 现象 | 原因与处理 |
|---|---|
| 手机打不开 | 确认手机和电脑是同一个 WiFi（不是 4G/5G） |
| 一直转圈 | 首次启动 Windows 可能弹防火墙提示，选「允许访问」 |
| 地址输错 | 黑窗口里显示的 `http://192.168.x.x:8931/` 才是手机用的，`127.0.0.1` 只有本机能用 |
| 换了 WiFi | 重新运行 `start.bat`，地址会变 |

> 注意：这种方式的地址是 `http://` 而不是 `https://`，
> 浏览器不允许在 http 下安装 App，所以要装到桌面请用第一节的在线版。

**用完记得关掉黑窗口**，服务不会留在后台。

---

## 五、其他托管平台（Vercel / Netlify）

仓库里的 `site/` 文件夹就是可以直接发布的成品。

- **Netlify**：打开 <https://app.netlify.com/drop>，把 `site` 文件夹拖进去，30 秒出网址
- **Vercel**：New Project → 选这个仓库 → 框架选 Other → 输出目录填 `site` → Deploy

---

## 六、装到手机桌面（像 App 一样）

### 安卓

打开在线版网址后，顶栏会出现一个 **⬇** 按钮，底栏也会弹一条
「装到桌面，下次一秒打开」的提示，点「安装」即可。

没看到提示的话，手动装：浏览器右上角 **⋮** → **添加到主屏幕**。

### iPhone / iPad

iPhone 的 Safari 不会自动提示安装，只能手动：

1. **必须用 Safari** 打开（微信里的浏览器不行）
2. 点底部中间**分享**按钮
3. 往下找 **添加到主屏幕**
4. 右上角点 **添加**

### 微信里打开

装不了。点右上角 **···** → **在浏览器打开**，再按上面的方法装。

### 装上之后

- 有自己的图标，全屏运行，没有地址栏
- 断网也能打开界面（**但天气数据必须联网**，取不到会明确提示）
- 我更新了代码，你下次打开会提示「有新版本 → 立即更新」

## 常见问题

**Q：打开是空白页 / 只有文字没有样式？**

说明 `index.html` 和同目录的 `.js` 文件分开了。
要么用**单文件版**（`知时智农-单文件版.html`），要么确保整个 `web` 文件夹完整。

**Q：页面顶部显示「离线数据 / 取数失败」？**

当前网络不通。本工具需要联网获取实时气象数据。
检查网络后点右上角「刷新」重试。

**Q：「用我的位置」点了没反应？**

浏览器规定定位功能只能在 `https` 或 `localhost` 下使用。
用在线版（https），或者用 `start.bat` 启动本地服务。

**Q：需要注册账号吗？**

不需要。所有数据存在你自己浏览器里（localStorage），
换电脑或换浏览器不会同步，属于正常现象。

**Q：为什么第一次打开没有地块？**

默认预置了 4 个示例地块。点左下角「+ 新增地块」添加自己的地，
支持搜索地名、地图点选、输入经纬度三种方式。

**Q：数据准确吗？能直接照着种地吗？**

不能。这是**决策参考工具**，所有判断基于公开气象数据和公开农技
常识规则计算得出，用于辅助判断趋势和时间窗口。

实际农事操作（用药种类、用量、安全间隔期等）请务必以
**当地农技部门指导意见**和**农药标签说明**为准。

**Q：为什么同一个建议会显示「置信度 中」？**

因为它来自集合预报——50 个气象模型各算一遍，只有一半左右支持这个窗口。
置信度「低」意味着建议仅供参考，建议临近再看。

**Q：为什么看不到 AI 润色了？**

公开版本前端**不放** API key（按量计费，公开就等于送人），
所以默认是**纯规则引擎**模式：问答页右上角显示「纯规则引擎」。

想打开 AI，两种办法任选其一：

1. **自己部署一个中转**（推荐，约 10 分钟，免费）
   按 `worker/README.md` 在 Cloudflare 部署一个 Worker，
   然后进「我的 → AI 对话」把中转地址填进去，点「测试连接」。
   key 在服务端，别人看源码也偷不到。

2. **只在本机直连**（自己用）
   新建 `web/config.local.js`，写自己的 key。

两种都不影响结论——所有数字本来就是规则引擎算出来的，
AI 只负责把话说顺。

**Q：手机上那三个按钮是什么？**

底部三个 Tab：**内容 / 对话 / 我的**。
电脑上没有底部 Tab，对应的是左侧栏顶部那三项，功能完全一样。

「我的」里可以改**农事阈值**（风速上限、气温区间、作业时段、降水拦截）。
当地农技部门有明确标准就直接改这里，点「保存并重算」立刻生效，不用改代码。

**Q：地点能精确到村吗？**

能识别就显示到村，识别不到会如实退到下一级：

- 有对应村庄数据时：`保定市 · 东洼村`
- 只到乡镇/街道时：`保定市 · 药都街道`
- 连乡镇都没有时：`保定市 · 竞秀区`

界面会标注精确到哪一级，**不会拿乡镇名冒充村名**。
村名来自地图服务商的公开 POI 数据，不是官方行政区划库，
个别地块识别不到属正常现象。

**Q：气象数据用的哪一家？**

主预报用**和风天气**（168 小时逐时，同化了国内地面站网，更贴县域实况）；
置信度和多模式分歧用 Open-Meteo 的集合预报。
侧栏底部会如实写出这一次的数据到底来自谁。

## 功能速览

| 模块 | 说明 |
|---|---|
| 最佳打药窗口 | 未来 7 天逐小时筛选，给出时段、置信度、推迟代价、关闭条件 |
| 反事实推演 | 点「如果风速收紧到 2.0」等按钮，真的重算一遍，看结论会不会翻转 |
| 今日判读 | 打药 / 灌溉 / 晾晒三种作业分别给结论 |
| 未来七天 | 三个作业维度切换查看 |
| 问一句 | 问哪天打药、要不要浇水、能不能晾晒 |
| 逐小时图表 | 风速、作业窗口热力图、温度降水、长势走势 |
