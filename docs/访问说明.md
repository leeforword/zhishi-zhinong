## 一、一句话说明这是什么

**把"未来几天的天气"翻译成"哪天几点能下地干什么"。**

农户真正要决定的不是"明天几度"，而是"这药今天能不能打、几点能打、下一次机会是几号"。
知时智农对**打药、灌溉、晾晒**三件事分别给出**逐时窗口 / 墒情与灌水定额 / 适宜日**，
每个数字都能在「我的 → 依据库」里查到文件出处。

它**不做**三件事：不诊断病虫害、不推荐药剂品种、不给用药剂量。

## 三、30 秒上手（建议体验顺序）

| 步 | 操作 | 你会看到 |
|---|---|---|
| 1 | 打开链接，停在「决策」页 | 一句结论（今天能不能打）+ 下一次窗口的具体日期与时段 + 四项实测指标 |
| 2 | 点上方 **灌溉** | 结论换成"该不该浇"，指标变成 墒情（估算）/ 生育期 / 建议定额 / 日耗水 |
| 3 | 点左侧（手机在抽屉里）换一块地 | 结论随之改变——不同地块、不同日期，窗口不一样 |
| 4 | 点底部 **问答**，问「这周哪天能打」，再追一句「那后天呢」 | 第一问给逐日清单，追问能听懂"那后天"指的是什么、什么药 |
| 5 | 点底部 **我的 → 依据库** | 13 份属地标准 + 15 份施药依据 + 10 份灌溉依据，每条带编号、机构、原文链接 |

## 四、建议评委重点看这 6 处（对应评审侧重）

1. **定位与知识范围**：「我的 → 作业标准」写明按哪个市的现行文件执行、哪几项是工具设定；
   「依据库」里每条都能点开原文。
2. **知识准确性**：决策卡下面四项指标（风速 / 降雨概率 / 露点差 / 窗口长度）与「数据与依据」
   里的逐时表、八张图同源；对话展开层会写"依据 N 份"，不写空话。
3. **对话体验**：问「有露水能打吗」「风这么大会飘到邻田吗」，它会先答这个现象，而不是复述"今天不能打"；
   问「这周哪天能打草甘膦」，它会认出具体药名并只答这一类药的窗口。
4. **诚实边界**：问「小麦叶子发黄是什么病」，它会明确说这不在能力范围内，不编答案。
5. **实用性**：手机端可安装到桌面（PWA），断网仍能打开界面；单文件版可离线演示。
6. **AI 运用深度**：所有数字由本地规则引擎算出；大模型只做意图识别与话术润色，
   且输出要过"数字 / 时间点 / 问题对象"三重一致性校验，失败就回退模板——**关掉 AI，结论与数字完全不变**。

## 五、它能回答什么、不能回答什么

**能答（有数据、有依据）**

- 今天 / 明天 / 这周哪天、几点到几点适合打药，为什么这个时间；
- 换个药类（除草剂 / 杀虫剂 / 杀菌剂）或具体药名（如苯磺隆、草甘膦）后的窗口变化；
- 露水、飘移、喷后遇雨、低温、逆温、高温这些具体气象风险；
- 这块地该不该浇水、浇多少方/亩、什么时候浇（按生育期与灌溉方式）；
- 这几天适不适合晾晒 / 入库；
- 判定用了哪些阈值、来自哪份文件、结论有多可靠。

**不答（明确拒绝，不硬编）**

- 病虫害诊断、药剂品种推荐、配药剂量与混配；
- 粮价、补贴、政策解读；
- 超出河北省范围的地块（地图视野与行政区划数据只覆盖河北及周边）。

## 六、稳定性与兜底（评委打不开时怎么办）

在线版部署在 GitHub Pages，国内网络偶尔会慢。材料里同时给了三条路：

1. **扫码**（手机网络通常比评委电脑快）；
2. **离线单文件**：`知时智农-单文件版.html`，双击即开，功能与在线版一致（除地图底图需联网）；
3. **演示录屏**：`演示录屏.mp4`（≤3 分钟），即使完全断网也能看到完整流程。

界面本身也有兜底：天气接口取不到数据时，会明确提示"没取到实时数据"，
**不会拿缓存或示例数据冒充实时结果**；地图加载失败会自动降级为本地行政区划示意图，点选与保存照常可用。

## 七、技术上值得说清的两件事

**1. 数字不由大模型产生。**
逐时天气 → 规则引擎（`logic.js` / `chem.js` / `irrig.js`）→ 结构化结论 → 界面。
大模型只在"听懂问题"和"把结论说顺"两步出现，输出还要通过校验：
新出现的数字、被改掉的时间点、被换掉的问题对象，任何一条不过就丢弃重来，回退模板。

**2. 依据是可查的，不是"AI 说的"。**
13 份河北省 / 市级作业标准、15 份施药判定依据、10 份灌溉依据，
每条都有编号、发布机构、条款要点、原文链接与查证日期（2026-11）。

## 八、已知不足（如实说明）

- **墒情是估算值**：没有接入土壤墒情传感器，按"参考蒸散 × 作物系数 − 有效降水"推算 0–40cm 相对含水量，
  界面上标注"估算"，误差约 ±10%；有实测数据时应以实测为准。
- **标准未经属地逐项核定**：阈值来自公开文件，覆盖河北 11 个地市，但未请当地农技部门逐条确认；
  界面提供「手动校准」以便按本地要求收紧。
- **只覆盖河北及周边**：省外地块不判。
- **长势/遥感未接入**：界面里没有假装做。
