# 部署与安装 · 手把手

> 目标：把这个项目变成一个**手机能装、电脑能开、任何网络都能访问**的网址。
> 全部免费，不需要服务器，不需要备案。

---

## 一、这件事的整体样子

```
你的电脑                      GitHub                        你的手机
─────────                    ───────────                    ─────────
改代码 → git push  ────────→  仓库 → Actions 自动构建  ────→  打开网址
                              → GitHub Pages 发布             → 点「安装」
                                                              → 桌面出现图标
```

没有后端、没有数据库。整个网站就是一堆静态文件，GitHub 免费帮你放着，
免费给你一个 `https` 网址。**HTTPS 是能安装 App 的前提**，所以用 GitHub Pages
比自己随便找个空间省事得多。

## 二、第一次发布（约 10 分钟）

### 第 1 步：在 GitHub 建空仓库

1. 登录 <https://github.com>，右上角 **+** → **New repository**
2. **Repository name** 填 `zhishi-zhinong`
3. 可见性选 **Public**
   > 私有仓库的 Pages 要付费账号才能用，免费的必须是 Public。
4. **不要**勾选 "Add a README file"（我们本地已经有了）
5. 点 **Create repository**

### 第 2 步：先打开 Pages

**这一步要在推送之前做**，否则第一次推送触发的部署会因为"仓库还没启用 Pages"而失败。

1. 仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 **GitHub Actions**（不要选 "Deploy from a branch"）
3. 不用点 Save，选完即时生效

> 选完之后这个页面会提示 "GitHub Pages is set up to publish from GitHub Actions"，
> 到这里就可以了，先别急着看到网址。

### 第 3 步：把本地代码推上去

仓库已经初始化好并提交过一次了，你只需要加个远程地址再推：

```bash
cd D:\zhishi-zhinong

git remote add origin https://github.com/lixiangzhi0000/zhishi-zhinong.git

git branch -M main
git push -u origin main
```

第一次推送会弹出登录窗口。**密码要填 Personal Access Token，不是账号密码**：

1. GitHub → 右上角头像 → **Settings** → 左下 **Developer settings**
2. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
3. Note 随便写（比如 `zhishi-push`），Expiration 选 90 天
4. 勾选 **repo** 这一项（下面几个子项会自动勾上）
5. 生成后**立刻复制**那串 `ghp_...`（关掉页面就再也看不到）
6. 回到命令行，用户名填 GitHub 用户名，密码粘贴这串 token

> 也可以装 GitHub Desktop 用图形界面推，不用碰 token。

推完之后：

1. 回到仓库 **Actions** 标签，会看到「部署到 GitHub Pages」正在跑
2. 等 1～2 分钟变成绿色 ✅
3. 访问：

```
https://lixiangzhi0000.github.io/zhishi-zhinong/
```

> 每次 `git push` 到 main，都会自动重新构建和发布，不用再点任何东西。

**如果 Actions 报错，按这个顺序排查：**

| 报错位置 | 原因 | 处理 |
|---|---|---|
| `Configure Pages` / `Deploy` 404 | 仓库还没启用 Pages | 回到第 2 步，Source 选 **GitHub Actions**，再去 Actions 页点 **Re-run jobs** |
| `跑规则引擎测试` 红 | 代码逻辑测试没过 | 本地 `node web/test-logic.mjs` 看哪一项挂了 |
| `构建静态站点` 红 | 构建自检没过 | 本地 `node scripts/build-site.mjs`，它会打印具体哪一条不通过 |
| 全部成功但页面 404 | 访问路径少了仓库名 | 地址必须以 `/zhishi-zhinong/` 结尾 |

## 三、把地图 key 绑定到你的域名（重要）

高德 key 是公开写在 `web/config.js` 里的。防止别人拿去用，必须绑域名：

1. 打开 <https://console.amap.com>
2. 应用管理 → 找到你的应用 → **设置**
3. 找到「域名白名单」，填入：

```
*.github.io
```

> 如果只想放行自己的站，填 `lixiangzhi0000.github.io`。
> 注意：高德这个 key 是「Web端(JS API)」类型，只能用于 JS API，
> 不能调 REST 接口，这是平台限制，不是配置错了。

**这一步不做会怎样**：短期没事，但如果别人把 key 抄走挂到自己站上，
额度算你的。几分钟的事，建议顺手做掉。

## 四、把网站装到手机

### 安卓（Chrome / Edge / 三星浏览器）

打开网址后，**顶栏会出现一个 ⬇ 按钮**，底栏也会弹一条提示：

> 装到桌面，下次一秒打开 → [安装]

点「安装」，桌面上就有图标了。

如果两个都没出现，手动装：浏览器右上角 **⋮** → **添加到主屏幕** / **安装应用**。

### iPhone / iPad

iPhone 的 Safari **不支持**网页自动弹出安装提示，只能手动：

1. **必须用 Safari** 打开（微信、QQ 里的浏览器不行）
2. 点屏幕**底部中间**的分享按钮（方框带向上箭头）
3. 列表里往下找，选 **添加到主屏幕**
4. 右上角点 **添加**

装好后从桌面图标打开，是全屏的，没有地址栏。

### 在微信里打开怎么办

微信内置浏览器既不能安装，也给不了「添加到主屏幕」的入口。页面会直接提示：

> 想装到桌面，先换个浏览器 —— 点右上角 **···** → **在浏览器打开**

这是微信的限制，不是网站的问题。

## 五、装上去之后有什么用

| 好处 | 说明 |
|---|---|
| 独立图标 | 不用每次翻浏览器书签 |
| 全屏运行 | 没有地址栏，像原生 App |
| 断网能开 | 界面从本地缓存打开，**但天气数据必须联网**，取不到会明确提示 |
| 秒开 | Service Worker 缓存了应用外壳 |
| 自动更新 | 我改了代码，你下次打开会提示「有新版本 → 立即更新」 |

> **关于断网的诚实说明**：我们**故意**不缓存天气接口的返回。
> 如果缓存了昨天的天气并当成本次结果展示，你可能按过期数据决定打不打药——
> 这比打不开危险得多。宁可诚实地说"取不到"，也不给一个看起来正常的旧答案。

## 六、以后改东西怎么发布

```bash
cd D:\zhishi-zhinong

# 改完代码后
node scripts/build-site.mjs        # 先本地构建一遍，自检不过就别推
git add -A
git commit -m "说明这次改了什么"
git push
```

等 Actions 跑完（1～2 分钟），刷新页面就是新版。

手机上已安装的版本会在下次打开时提示更新。

> 注意：`web/config.js` 里的东西改了要重新 push；
> `web/config.local.js` 是本地私有的，改它不会影响线上。

## 七、常见问题

**Q：为什么 Actions 里 `npm install` 那步没有？**
A：这个项目零第三方依赖，不需要安装任何包。所有脚本只用 Node 内置模块。

**Q：能不能用自己买的域名？**
A：可以。仓库 Settings → Pages → Custom domain 填进去，再去域名服务商加一条
CNAME 记录指向 `lixiangzhi0000.github.io`。GitHub 会自动帮你申请 https 证书。

**Q：能部署到 Vercel / Netlify 吗？**
A：能，而且更简单：把 `site/` 文件夹整个拖进 <https://app.netlify.com/drop> 就行。
但要注意 iOS 安装同样要求 https，这几家都默认给你。

**Q：`dist/` 和 `site/` 有什么区别？**
A：
- `site/` 是**发布用**的静态站点，GitHub Pages 直接用它，已提交到仓库。
- `dist/` 是本地打包产物（单文件版 html、zip 压缩包），已被 `.gitignore` 忽略，
  只留在你自己电脑上。

**Q：手机上打开是空白 / 图标是灰的？**
A：多半是没走 https 或缓存了半截。确认网址是 `https://`；
然后浏览器设置里清一下该站的缓存，或者先把图标删掉重装一次。

**Q：改了 `web/` 里的东西，但线上没变？**
A：三个常见原因：
1. 忘了 push；
2. Actions 还在跑（去 Actions 标签看进度）；
3. 手机上装的是旧版缓存——关掉 App 重开，会看到"有新版本"的提示。
